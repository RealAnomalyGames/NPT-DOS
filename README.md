# NPT-DOS 1.0

### A command-line operating system by Neptune Corporation.

NPT-DOS is a 32-bit x86 operating system developed by Neptune Corporation. Built around a dedicated command-line environment and a custom persistent filesystem, NPT-DOS provides a straightforward computing experience with its own installer, shell, and system utilities.

Free to download and use. Source code publicly available. Proprietary software.

## Overview

NPT-DOS is designed as an independent, lightweight operating system with a classic DOS-inspired identity. It boots into its own command-line environment and includes tools for interacting with files, inspecting system information, and managing the system.

Version 1.0 marks the first official release of NPT-DOS.

## Features

* Dedicated command-line shell — interact with NPT-DOS through its own command environment.
* Built-in installer — install NPT-DOS onto a compatible storage device.
* NPTFS filesystem — a custom filesystem designed for persistent file storage.
* File management — create, inspect, copy, edit, and manage files and directories using supported commands.
* System utilities — access system information, memory information, dates, times, and other built-in tools.
* Bootable installation media — start the installer using the official NPT-DOS ISO.
* Publicly available source code — inspect the source code under the terms of the NPT-DOS License Agreement.

## Getting Started

1. Download NPT-DOS

Download the NPT-DOS 1.0 ISO from an official distribution channel.

2. Start the installer

Boot your compatible system from the installation media. Follow the on-screen instructions provided by the installer.

3. Install NPT-DOS

Select the intended installation target and proceed through the installation process.

Warning: Installation and filesystem-formatting operations can erase data. Use a dedicated target and back up any important files before proceeding. Do not select a drive containing data you wish to preserve.

4. Start using NPT-DOS

After installation, boot from the installed system to enter the NPT-DOS command-line shell.

Enter HELP to view the available commands.

For additional instructions and troubleshooting, consult the NPT-DOS user documentation published by Neptune Corporation.

## System Compatibility

NPT-DOS 1.0 targets 32-bit x86 systems. Compatibility depends on the system’s hardware, firmware, and storage configuration.

The operating system uses a supported ATA storage configuration; systems with different storage controllers or configurations may not work.

Review the release documentation for any additional compatibility information before installing on physical hardware.
